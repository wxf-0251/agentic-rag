Streaming Strategy — 4 Channels

How progress reaches the UI in real-time
Stream Trigger Content UI Element
outline_stream Planner completes Report outline JSON Chapter cards with progress bars
research_stream Each Researcher completes Query + sources found Animated progress cards
draft_stream Writer yields tokens Markdown text chunks Streaming markdown in main panel
review_stream Reviewer completes PASS/FAIL + critique Status badge + re-search indicator

Implementation: LangGraph stream_mode + Streamlit callbacks

Code sketch — main.py

# LangGraph emits events per node execution
for event in graph.stream(
    {"query": user_query},
    stream_mode="updates",    # yields {node_name: output} per step
    config={"callbacks": [StreamlitCallbackHandler(st_placeholders)]}
):
    node_name = list(event.keys())[0]
    node_output = event[node_name]

    if node_name == "planner":
        render_outline(node_output["outline"], st_placeholders["outline"])
    elif node_name == "researcher":
        update_research_card(node_output, st_placeholders["research"])
    elif node_name == "writer":
        stream_section_text(node_output["text"], st_placeholders["draft"])
    elif node_name == "reviewer":
        show_review_status(node_output, st_placeholders["review"])

Report Rendering: Markdown + Charts + Citations

renderer.py capabilities
  • Markdown → HTML: Writer outputs clean Markdown; rendered with st.markdown()
  • Inline citations: [1], [2] style → linked to right-panel source list. Writer prompt enforces citation format
  • Auto charts: Writer outputs <chart> tags; renderer.py runs matplotlib → st.image(). Example: 
    <chart type="bar" title="Top 5 谐波减速器供应商">
  x: ["绿的谐波","日本哈默纳科","来福谐波",...]
  y: [35,28,15,...]
</chart>
  • Export: st.download_button → PDF (via weasyprint) or .md download
