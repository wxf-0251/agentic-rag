Agentic RAG — System Architecture

4-Agent Pipeline with LangGraph Orchestration & Reasoning Loop

4-Stage Pipeline

Agentic RAG Reasoning Loop
Stage 1: Planner Agent (Claude Opus 4)
Input: "分析2026年人形机器人核心供应链及投资风险"
→ Decompose into 5-7 sub-questions
→ Generate report outline with chapters
→ Classify each sub-question by data source type
Stage 2: Researcher Agents (Haiku 4, N parallel)
Router per sub-question:
• "Latest funding news" → Tavily Search API
• "Harmonic reducer technology" → Local Chroma DB
• "Tesla stock trend" → Yahoo Finance API
→ Retrieved context + source citations stored in shared state
Stage 3: Writer + Reviewer Loop (Opus 4)
Writer drafts section → Reviewer critiques:
• "Sufficient citations to support claims?"
• "Any data inconsistencies?"
• "Logical gaps in reasoning?"
→ FAIL: triggers re-search with refined keywords
→ PASS: section finalized
Stage 4: Streaming Output via Streamlit
Real-time: outline → research progress → draft → final report
Markdown + inline citations + auto-generated charts (matplotlib)

LangGraph State Machine

StateGraph with Conditional Edges
[START] user_query
↓
planner_node
↓
researcher_1 researcher_2 researcher_N
(parallel via LangGraph Send API)
↓
writer_node
↓
reviewer_node
↖ FAIL: re-search | PASS: continue →
↓
[END] final_report

Key Design Decisions

  • Not linear — Reviewer→Researcher loop = conditional edges in LangGraph
  • Router per sub-question — not one retrieval fits all
  • Shared typed state — TypedDict passed through all nodes
  • Streaming at every stage — user sees live progress, not a spinner
