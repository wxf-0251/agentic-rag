Core Components

Agent Responsibilities
Agent Model Input Output
Planner Opus 4 User query string List[SubQuestion] + ReportOutline
Researcher Haiku 4 SubQuestion + data_source RetrievedContext + List[Citation]
Writer Opus 4 SectionOutline + all research ReportSection (markdown)
Reviewer Opus 4 ReportSection + sources ReviewVerdict (PASS / FAIL + reason)

Shared State (AgentState)

TypedDict — single source of truth through the graph
class AgentState(TypedDict):
    # Input
    query: str
    # Planner output
    sub_questions: List[SubQuestion]
    outline: ReportOutline
    # Researcher output (accumulated)
    research_results: dict  # {question_id: RetrievedContext}
    citations: List[Citation]
    # Writer output (accumulated)
    completed_sections: List[ReportSection]
    current_section_idx: int
    # Reviewer output
    review_history: List[ReviewResult]
    # Control flow
    search_iteration: int       # tracks re-search loop depth
    max_iterations: int         # safety limit (default 3)
    # Streaming
    progress_messages: List[str]
