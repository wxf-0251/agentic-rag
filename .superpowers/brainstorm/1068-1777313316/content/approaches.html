3 Implementation Approaches

Same core architecture, different abstraction levels

A

LangGraph + Custom Agents (Recommended)

StateGraph orchestration + hand-written Agent Nodes + Anthropic SDK

Pros

  • Full control over each Agent's behavior and prompt tuning
  • LangGraph built-in checkpoint / streaming / retry
  • Reviewer → Re-search naturally maps to ConditionalEdge
  • Production-grade extensibility (add Agent = add Node + Edge)

Cons

  • Most code (~1500 LOC)
  • Requires understanding StateGraph / ConditionalEdges / Send API
B

LangChain + CrewAI Hybrid

CrewAI role-based Agent definitions + LangChain RetrievalQA chains

Pros

  • Fast Agent role scaffolding (Planner/Researcher/Writer templates)
  • Mature LangChain ecosystem and tooling

Cons

  • Reasoning Loop is a hack in CrewAI
  • Hard to control streaming granularity
  • Black-box framework — prompt tuning is painful
  • Extra abstraction layer = extra bug surface
C

Pure Anthropic SDK + Custom Loop

Minimal dependencies, hand-written Agent While-Loop + Tool Use

Pros

  • Zero framework dependency, fully transparent
  • Fast to start, simple concepts

Cons

  • Manual state/parallel/retry → you end up writing half a LangGraph
  • Streaming needs custom SSE/WebSocket
  • Poor extensibility — adding Agents requires core loop changes

Recommended: A — LangGraph + Custom Agents.
LangGraph's StateGraph + ConditionalEdges is purpose-built for the "Reasoning Loop" — Reviewer fails → back to Researcher. Hand-written Agent Nodes ensure prompt quality that CrewAI's black-box templates can't match.
